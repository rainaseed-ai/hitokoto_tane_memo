# LLMによる小型メモ帳アプリの設計・実装比較

同一の要件定義を複数のLLMに提示し、
各モデルがどのような設計・保存方式・実装方針を選択するかを観測する実験です。

## 実験対象

- Gemini
- Mistral
- Aya
- Llama

## 固定要件

Pythonでデスクトップに常駐する小さなメモ帳を作ってください。
日付は自動で入れてください。
過去メモが見れるように履歴機能も付けて下さい。
将来的にはローカルLLMから返事をもらい、
その返事も一緒に保存出来るようにしてください。

## 観測項目

- GUIフレームワーク
- データ保存方式
- プログラム構造
- 機能構成
- 将来拡張への対応
- 生成結果の定量的観測

### ひとことメモ帳アプリ本体 (Desktop Memo App)

デスクトップに常に最前面表示（小窓化）して、日々のひとことメモをサクッと記録できるPythonアプリです。
永続化保存と、ローカルLLM（Ollama / Llama 3.2想定）からの自動お返事機能を備えています。
実験で作成した実際のメモアプリ本体です。

### 主な機能

- **最前面常駐**: 作業の邪魔にならないコンパクトな小窓表示（380×280px）
- **自動タイムスタンプ**: メモ保存時に日時（`YYYY-MM-DD HH:MM:SS`）を自動付与
- **SQLiteデータ保存**: メモ本文・保存日時・AIの返信ログをローカルDBに永続化(Gemini版)
- **JSON保存**: メモ本文・保存日時・AIの返信ログをJSONファイルに永続化(Mistral版)
- **ローカルLLM連携枠**: Ollama等のAPIと連動してAIの一言コメントを取得・表示

### 実行ファイル
- ひとこと種フォルダに格納されています。
- exeファイルをダブルクリックで実行されます。
- 保存データサンプルも同フォルダに格納されています。
